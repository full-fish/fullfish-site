VocaTray 개인정보처리방침

시행일: 2026년 10월 27일

VocaTray(이하 "앱")는 컴퓨터 작업 표시줄에서 영어 단어를 외우는 데스크톱 앱이에요. 회원가입이 없고, 개발자는 이용자의 학습 기록을 모으는 서버를 두지 않아요. 앱 소개는 VocaTray 홈페이지에 있어요.

1. 컴퓨터 안에만 저장하는 정보

다음 정보는 이용자의 컴퓨터에만 저장되고 개발자에게 전송되지 않아요.

  • 기기 ID: 컴퓨터 이름과 임의의 문자 4개로 만든 이름(예: my-pc-3f2a). 여러 컴퓨터의 학습 기록 파일을 서로 구분하는 데만 써요.
  • 학습 기록: 고른 단어장, 외운 단어와 외웠다고 표시한 시각, 다시 외울 단어로 되돌린 단어와 그 시각.

저장 위치는 Windows는 %APPDATA%\com.vocatray.desktop, macOS는 ~/Library/Application Support/com.vocatray.desktop 폴더예요.

2. Google 드라이브 연결 (선택)

여러 컴퓨터에서 같은 학습 기록으로 이어서 외우고 싶을 때만 Google 계정을 연결해요. 연결하지 않아도 앱의 모든 학습 기능을 쓸 수 있어요.

  • 요청하는 권한: https://www.googleapis.com/auth/drive.appdata 하나뿐이에요. 이 권한으로는 Google 드라이브 안에 이 앱 전용으로 만들어지는 숨김 폴더(앱 데이터 폴더)에만 접근할 수 있어요. 내 드라이브의 다른 파일과 폴더는 보거나 바꿀 수 없어요.
  • 올리는 정보: 1번의 기기 ID와 학습 기록을 담은 파일(progress.기기ID.json)을 컴퓨터마다 하나씩 올려요.
  • 읽는 정보: 같은 폴더에 있는, 이용자의 다른 컴퓨터가 올린 학습 기록 파일을 읽어 내 컴퓨터의 기록과 합쳐요.
  • 요청하지 않는 정보: Google 계정의 이름, 이메일 주소, 프로필 사진, 연락처, 그 밖의 드라이브 파일은 요청하지 않아요.
  • 로그인: 기본 웹 브라우저에 뜨는 Google 로그인 화면에서 해요. 앱은 비밀번호를 볼 수 없어요. 로그인 뒤 받은 인증 토큰은 운영체제의 자격 증명 저장소(Windows 자격 증명 관리자, macOS 키체인)에만 보관해요.
  • 전송 경로: 학습 기록은 이용자의 컴퓨터와 Google 서버 사이에서 암호화된 연결(HTTPS)로만 오가고, 개발자의 서버를 거치지 않아요.
  • 쓰는 목적: Google 드라이브에서 받은 데이터는 여러 컴퓨터의 학습 기록을 맞추는 데만 써요. 광고, 판매, AI 모델 학습에 쓰거나 다른 사람에게 넘기지 않아요.
VocaTray's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

(VocaTray가 Google API로 받은 정보를 쓰고 다른 앱으로 옮기는 일은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따라요.)

3. 개발자에게 전송되는 정보

없어요. 앱에는 사용 통계(애널리틱스), 광고, 오류 보고를 수집하는 기능이나 외부 SDK가 들어 있지 않아요.

4. 제3자 서비스

  • Google 드라이브 · Google 로그인 (Google LLC): 2번의 연결을 켠 경우에만 써요. Google이 처리하는 정보는 Google 개인정보처리방침을 따라요.

5. 보관 기간과 삭제

  • 컴퓨터의 기록: 이용자가 지울 때까지 보관해요. 앱을 지운 뒤 1번의 저장 폴더를 지우면 모두 지워져요.
  • Google 연결 끊기: 앱 메뉴에서 연결을 끊으면 컴퓨터에 보관한 인증 토큰을 지워요. Google 계정 → 서드파티 앱 및 서비스에서 VocaTray의 권한을 직접 없앨 수도 있어요.
  • 드라이브에 남은 기록: Google 드라이브 웹 → 설정 → 앱 관리 → VocaTray → 옵션 → "숨겨진 앱 데이터 삭제"로 지울 수 있어요.

6. 아동

앱에는 초등 수준 단어장이 있어요. 개발자는 이용자의 나이와 관계없이 개인정보를 수집하지 않아요. 만 14세 미만 어린이가 Google 드라이브 연결을 쓰려면 보호자와 함께 설정해 주세요.
