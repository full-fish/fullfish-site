VocaTray
작업 표시줄에서 외우는 영단어

작업 표시줄의 트레이 아이콘에 마우스를 올리면 영어 단어 카드가 뜹니다. 일하다가 잠깐씩 한 단어를 보고, 외운 단어는 [외웠어요]를 눌러 빼면 다시 나오지 않습니다. 2022 개정 교육과정 기본 어휘 3,000개를 초등·중학·고등 단어장으로 나눠 담았습니다.

개인정보처리방침서비스 약관

한눈에 보기

  • 마우스를 올리면 단어 카드: 단어, 발음 기호, 품사별 뜻, 예문과 한국어 해석을 보여 줍니다. 뜻에 따라 발음이 다른 단어(record, close, live 등)는 뜻마다 발음을 따로 적었습니다.
  • 클릭하면 [외웠어요] · [다음]: 외운 단어는 다시 나오지 않고, 단어장을 한 바퀴 다 돌기 전에는 같은 단어가 반복되지 않습니다.
  • 단어장 3권: 트레이 아이콘을 오른쪽 클릭해 단어장을 고릅니다.
  • 여러 컴퓨터에서 이어 하기 (선택): 구글 계정을 연결하면 집과 회사 컴퓨터에서 외운 단어가 서로 맞춰집니다.
  • 회원가입 · 광고 · 개발사 서버 없음: 학습 기록은 내 컴퓨터와, 연결한 경우 내 구글 드라이브에만 있습니다.

단어장

교육부 고시 제2022-33호 영어과 교육과정의 기본 어휘 목록(3,000개)에 표시된 학교급을 그대로 따릅니다.

단어장기준단어 수
초등 수준초등학교 권장 어휘 (*)800
중학 수준중·고등학교 공통 과목 권장 어휘 (**)1,200
고등 수준그 밖의 과목 어휘1,000

단어 목록은 교육과정 원문을 따르고, 뜻 · 발음 · 예문은 AI로 만든 초안을 검수하며 다듬고 있습니다.

구글 드라이브를 쓰는 이유

여러 컴퓨터에서 같은 학습 기록으로 이어서 외우려면 기록을 둘 곳이 필요합니다. VocaTray는 개발사 서버 대신 이용자 본인의 구글 드라이브를 씁니다. 연결은 선택이고, 연결하지 않아도 모든 기능을 쓸 수 있습니다.

  • 요청하는 권한은 하나뿐입니다: drive.appdata — 구글 드라이브 안에 VocaTray 전용으로 만들어지는 숨김 폴더에만 접근합니다. 내 드라이브의 다른 파일과 폴더는 보거나 바꿀 수 없습니다.
  • 저장하는 것: 컴퓨터마다 하나씩 만드는 학습 기록 파일(고른 단어장, 외운 단어와 그 시각)입니다. 다른 컴퓨터의 기록 파일을 읽어 합칩니다.
  • 오가는 길: 기록은 내 컴퓨터와 구글 서버 사이에서만 오갑니다. 개발사는 이 데이터를 받지 않습니다.
  • 로그인: 기본 웹 브라우저의 구글 로그인 화면에서 합니다. 앱은 비밀번호를 보지 못하고, 받은 로그인 토큰은 운영체제의 자격 증명 저장소(Windows 자격 증명 관리자, macOS 키체인)에 보관합니다.
  • 그만 쓰기: 앱에서 연결을 끊거나, Google 계정의 서드파티 연결에서 VocaTray의 권한을 없앨 수 있습니다. 드라이브에 남은 기록은 드라이브 설정 → 앱 관리에서 지울 수 있습니다.

자세한 내용은 개인정보처리방침에 있습니다.

지원 환경과 다운로드

  • Windows 10 · 11 (Microsoft Edge WebView2 사용)
  • macOS — 준비 중

Windows용 설치 파일 내려받기 (늘 최신 버전). 버전별 바뀐 내용은 GitHub 릴리스에 있습니다.

  1. 내려받은 VocaTray-setup.exe를 실행합니다. 관리자 권한은 필요 없습니다.
  2. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누릅니다. 코드 서명을 하지 않은 앱이라 뜨는 경고입니다.
  3. 설치가 끝나면 작업 표시줄 오른쪽의 ^(숨겨진 아이콘)에서 VocaTray 아이콘을 작업 표시줄로 끌어 두면 늘 보입니다. 다음 로그인부터는 자동으로 켜집니다.

In English

VocaTray is a desktop app by FULLFISH that shows an English vocabulary card when you hover over its icon in the system tray. It includes three word lists (800 / 1,200 / 1,000 words) based on the basic vocabulary of Korea's 2022 national English curriculum. Words you mark as memorized stop appearing.

How VocaTray uses Google user data: connecting a Google account is optional and only used to sync your learning progress between your own computers. VocaTray requests a single scope, https://www.googleapis.com/auth/drive.appdata, which limits access to a hidden folder that only VocaTray can see in your Google Drive. VocaTray stores one small progress file per computer there (selected word list, memorized words and timestamps) and reads the other computers' files to merge them. It cannot see or change any other file in your Drive, and the data goes directly between your computer and Google — FULLFISH never receives it. See the privacy policy (Korean) for details.
