1. 실패 원인 찾기#

예전 드론은 Arduino Pro Mini, GY-521, MX1508 모터 드라이버(HW-354) 2장, 615 코어리스 모터 4개를 덕트형 프레임에 얹은 구성이었습니다. 무게는 배터리를 빼고 36g, 650mAh 배터리를 달면 53g이었고, 모터를 끝까지 돌려도 뜨지 않았습니다.

추력/무게비=모터 4개 추력 약 68g전체 무게 53g≈ 1.3

추력이 무게보다 조금 큰 정도로는 떠오르기도 어렵고, 떠도 자세를 바로잡을 힘이 남지 않습니다. 쿼드콥터는 추력/무게비가 최소 2는 넘어야 합니다. 무게를 늘린 부품은 이렇습니다.

2. 새 설계 정하기#

방향은 두 가지입니다. 무거운 부품을 가벼운 것으로 바꾸고, 쓸 수 있는 부품은 그대로 씁니다. 참고한 드론은 ESP-FLY입니다. XIAO ESP32-S3, MPU6050, 615 코어리스 모터를 쓰는 같은 구성으로, 배터리 포함 25g에 추력 68g(추력/무게비 2.7)이고 250mAh 배터리로 5분 반쯤 납니다.

부품 구성#

  • 보드: Seeed XIAO ESP32-S3. 와이파이로 휴대폰에서 조종하고, 리튬 배터리 충전 회로가 들어 있어 USB-C로 바로 충전합니다.
  • 자세 센서: 갖고 있던 GY-521. 10년쯤 된 모듈이지만 센서 성능에는 문제가 없습니다. 조립 전에 제대로 응답하는지만 확인합니다 (7단계).
  • 모터 구동: AO3400A MOSFET 4개. MX1508 드라이버 대신 SOT-23 MOSFET으로 모터의 − 쪽을 켜고 끕니다(저측 스위칭). 3.3V 신호로도 충분히 켜지는 MOSFET이라 XIAO 핀에 바로 연결합니다.
  • 프레임 · 모터 · 프로펠러: 예전 것 재사용. 덕트형 프레임은 3D 프린팅으로 새로 만드는 것보다 가볍습니다.
  • 전원. 배터리를 XIAO 뒷면의 BAT 패드에 연결합니다. 배터리로 돌 때는 XIAO의 5V 핀에 전원이 나오지 않으니 쓰지 않습니다.
  • 프로펠러. 지금 것은 4엽입니다. 같은 지름의 3엽보다 추력은 더 나오지만 전류를 더 먹고 효율은 조금 낮습니다.

모터 방향과 배치#

대각선끼리 같은 방향으로 돌아야 기체가 제자리에서 돌지 않습니다. 배치는 ESP-FLY와 ESP-Drone 펌웨어의 기본 순서를 따릅니다.

  • 615 모터는 선 색으로 방향을 구분합니다. CW(시계)는 빨강/파랑, CCW(반시계)는 검정/흰색입니다.
  • 코어리스 브러시 모터는 전원 극성을 바꾸면 반대로 돕니다. CW 모터밖에 없으면 두 개를 +/−를 바꿔 연결해서 CCW로 쓸 수 있습니다. 이때는 선 색 규칙이 안 맞으니 표시를 해 둡니다.
  • 프로펠러도 방향이 있어서, 모터 방향에 맞는 것을 끼웁니다.

3. 무게 줄이기 (배선)#

전선은 굵을수록 무겁지만, 모터 전원선을 너무 가늘게 하면 전압이 떨어집니다. 그래서 전원선과 신호선의 굵기를 나눴습니다.

용도굵기무게 (실리콘 피복, 1m)
배터리 · 모터 전원선24~26AWG24AWG 약 3~3.5g, 26AWG 약 2g
신호선 (GY-521, MOSFET 게이트)30AWG약 1g

모터 4개를 합치면 3~4A가 흐릅니다. 전원선을 30AWG로 하면 10cm 왕복에서 약 0.27V가 떨어져 추력이 줄고, 전압이 순간적으로 내려가면 ESP32가 리셋될 수도 있습니다. 24AWG는 약 0.07V만 떨어집니다.

30AWG 전압 강하≈4A × 0.34Ω/m × 0.2m≈ 0.27V

배선 방식도 비교했습니다 (부품 무게는 빼고 배선만).

  • MOSFET, 다이오드, 저항만 약 1×2cm 만능기판 조각에 모읍니다. 0.5g쯤 늘지만 작은 SOT-23 다리가 떨어지지 않게 보호합니다.
  • GY-521은 XIAO 뒷면에 양면 폼테이프로 붙이고, 30AWG 5가닥(3V3, GND, SDA, SCL, INT)을 짧게 잇습니다. 폼테이프는 모터 진동도 흡수합니다.
  • 암헤더(소켓)는 쓰지 않습니다. 핀헤더보다 2배 넘게 무겁고 높이도 늘어납니다.

4. 배터리 고르기#

조건은 1S 300mAh, 방전율 25C 이상, PH2.0 커넥터, 8~9g입니다. 300mAh에 25C면 순간적으로 7.5A까지 낼 수 있어서 모터 4개가 먹는 3~4A를 넉넉히 감당합니다.

  • 일반용 300mAh 배터리(1C, 약 0.3A)는 전류가 모자라서 못 씁니다.
  • 보호회로가 달린 배터리(Adafruit 제품 등)도 못 씁니다. 보호회로는 보통 2~3A쯤에서 전원을 끊어서, 비행 중에 전원이 꺼집니다.
  • 국내 몰(아이씨뱅큐)에는 조건에 맞는 제품이 없어서 알리익스프레스에서 샀습니다.

고른 배터리는 GAONENG GNB 1S 300mAh 3.8V 60C HV (PH2.0, 5개)입니다. HV 타입이라 완충 전압이 4.35V지만, 일반 4.2V 충전기나 XIAO로 충전해도 안전합니다. 용량을 조금 덜 쓸 뿐입니다.

  • XIAO로 충전: 배터리를 꽂은 채 USB-C를 연결하면 약 100mA로 충전되어, 1개에 약 3시간 걸립니다.
  • 여러 개를 돌려 쓸 때: PH2.0 4포트 충전기(AOKoda CX405)가 있으면 편합니다.

보호회로 없는 배터리 다루기#

드론용 배터리는 위와 같은 이유로 일부러 보호회로 없이 나옵니다. 그래서 보호회로가 하던 일을 나눠서 챙깁니다.

5. 회로 설계#

모터 구동#

  • 모터 +는 배터리 +에, 모터 −는 MOSFET의 드레인(D)에 연결하고, 소스(S)는 GND로 갑니다. XIAO가 게이트(G)에 PWM 신호를 주면 MOSFET이 모터의 − 쪽을 켜고 끄면서 속도를 조절합니다.
  • 10kΩ 풀다운 (게이트–GND): 전원을 켜고 펌웨어가 핀을 잡기 전까지 게이트가 떠 있으면 모터가 저절로 돌 수 있습니다. 저항이 게이트를 GND 쪽으로 붙잡아 둡니다.
  • 다이오드 (모터와 나란히, 띠가 배터리 + 쪽): MOSFET이 꺼지는 순간 모터 코일에서 생기는 역기전력을 돌려보내 MOSFET을 보호합니다.

다이오드는 1N4148을 샀습니다. 같은 구성의 ESP-FLY도 1N4148을 쓰니 그대로 시작합니다. 다만 PWM으로 끌 때마다 모터 전류(약 1A)가 다이오드로 흐르고, 1N4148의 평균 정격(150~300mA)보다 큽니다. 첫 비행 뒤 다이오드가 뜨거우면 1A급 쇼트키 다이오드(SS14, B5819W)로 바꿉니다. 자리와 방향이 같아서 바꿔 끼우기만 하면 됩니다.

배터리 전압 감시#

XIAO ESP32-S3에는 배터리 전압을 읽는 회로가 들어 있지 않습니다. 그래서 10kΩ 저항 2개로 배터리 전압을 절반으로 나눠 ADC 핀에 넣습니다. 10kΩ는 최소 주문 수량이 10개라 풀다운 4개에 쓰고 남은 것으로 충분합니다.

  • 연결: 배터리 + → 10kΩ → D1 → 10kΩ → GND
  • D1(GPIO2)을 쓰는 이유: ESP-Drone 펌웨어가 배터리 전압을 이 핀에서만 읽도록 고정되어 있습니다. 설정 화면의 핀 번호를 바꿔도 실제로는 GPIO2를 읽습니다.
  • 완충 4.35V가 약 2.18V로 내려와 ADC가 읽을 수 있는 범위에 들어갑니다. 펌웨어에서 읽은 값에 2를 곱하면 배터리 전압입니다.
  • 분압 저항에는 항상 약 0.2mA가 흐릅니다. 그래서 보관할 때 배터리를 빼야 합니다.

7-3. GY-521 연결#

GY-521은 만능기판을 거치지 않고 선 5가닥으로 XIAO에 바로 연결합니다. 만능기판(7-5)에는 모터 구동 부품과 분압 저항만 들어갑니다. 앞 설계에서는 4가닥이었는데, 펌웨어를 확인해 보니 센서가 "새 값이 준비됐다"고 알려 주는 INT 신호에 맞춰 센서를 읽도록 되어 있어서 INT 선이 꼭 필요합니다. 이 선이 없으면 드론이 자세를 잡지 못합니다.

  1. 핀헤더 떼기. GY-521에 핀헤더가 달려 있으면 니퍼로 검은 플라스틱을 잘라 낸 뒤, 핀을 하나씩 인두로 녹이면서 핀셋으로 뽑습니다. 0.5g쯤 가벼워집니다.
  2. 전선 준비. 30AWG 전선 5가닥을 4cm로 자르고 양 끝 피복을 2mm씩 벗긴 뒤, 끝에 납을 살짝 먹입니다(예비 납땜).
  3. GY-521 쪽 납땜. 선을 부품 면(윗면)에서 VCC, GND, SCL, SDA, INT 구멍에 꽂고, 뒷면에서 납땜한 뒤 튀어나온 끝을 바짝 자릅니다. GY-521은 나중에 XIAO 바로 아래에 겹쳐 붙이기 때문에(7-10) 선이 XIAO 쪽인 윗면으로 나와야 합니다. XDA, XCL, AD0는 비워 둡니다.

7-4. GY-521 확인#

아래 코드를 아두이노 IDE에 새 스케치로 붙여 넣고 업로드한 뒤, Tools → Serial Monitor를 열고 오른쪽 아래 속도를 115200으로 맞춥니다.

// GY-521 확인: I2C 주소, WHO_AM_I, INT 신호, 기울기 방향
#include <Wire.h>

const int PIN_SDA = 5;   // D4
const int PIN_SCL = 6;   // D5
const int PIN_INT = 8;   // D9
const uint8_t MPU = 0x68;

volatile uint32_t intCount = 0;
void IRAM_ATTR onInt() { intCount++; }

void writeReg(uint8_t reg, uint8_t val) {
  Wire.beginTransmission(MPU);
  Wire.write(reg);
  Wire.write(val);
  Wire.endTransmission();
}

uint8_t readReg(uint8_t reg) {
  Wire.beginTransmission(MPU);
  Wire.write(reg);
  Wire.endTransmission(false);
  Wire.requestFrom(MPU, (uint8_t)1);
  return Wire.available() ? Wire.read() : 0xFF;
}

void setup() {
  Serial.begin(115200);
  delay(3000);  // 시리얼 모니터를 열 시간
  Wire.begin(PIN_SDA, PIN_SCL);

  Serial.println("== I2C 스캔 ==");
  for (uint8_t addr = 1; addr < 127; addr++) {
    Wire.beginTransmission(addr);
    if (Wire.endTransmission() == 0) Serial.printf("응답한 주소: 0x%02X\n", addr);
  }
  Serial.printf("WHO_AM_I = 0x%02X (0x68이어야 정상)\n", readReg(0x75));

  writeReg(0x6B, 0x00);  // 잠자기 해제
  writeReg(0x19, 0x07);  // 1초에 1000번 측정
  writeReg(0x38, 0x01);  // 측정할 때마다 INT 신호 내보내기
  pinMode(PIN_INT, INPUT);
  attachInterrupt(digitalPinToInterrupt(PIN_INT), onInt, RISING);
}

void loop() {
  Wire.beginTransmission(MPU);
  Wire.write(0x3B);  // 가속도 X부터 14바이트
  Wire.endTransmission(false);
  Wire.requestFrom(MPU, (uint8_t)14);
  int16_t v[7];
  for (int i = 0; i < 7; i++) {
    uint8_t hi = Wire.read();
    uint8_t lo = Wire.read();
    v[i] = (int16_t)((hi << 8) | lo);
  }
  uint32_t n = intCount;
  intCount = 0;
  Serial.printf("가속도 X %6d  Y %6d  Z %6d | 자이로 X %6d  Y %6d  Z %6d | INT %lu회/초\n",
                v[0], v[1], v[2], v[4], v[5], v[6], (unsigned long)n);
  delay(1000);
}

GY-521을 부품 면이 위로 오게 책상에 평평하게 놓고 아래처럼 나오는지 봅니다.

확인할 것정상아니면
응답한 주소0x68아무것도 없으면 SDA·SCL이 바뀌었거나 납땜 불량. VCC·GND 확인
WHO_AM_I0x68다른 값(0x70, 0x72 등)이면 MPU6050이 아닌 호환 칩이라 펌웨어가 인식하지 못함. GY-521을 새로 사야 함
INT약 1000회/초0이면 INT 선(D9) 납땜 확인
가속도 Z약 +16000 (16384가 1g)음수면 센서가 뒤집혀 있음
가속도 X, Y0 근처 (±1000 안쪽)

기울기 방향 확인: GY-521 기판에는 X, Y 화살표가 인쇄되어 있습니다. 화살표가 가리키는 쪽을 들어 올리면 그 축의 값이 +로 커져야 합니다. Y 화살표 쪽을 들면 Y가 +, X 화살표 쪽을 들면 X가 +인지 봅니다. 나중에 프레임에 붙일 때 이 화살표 방향을 씁니다(7-11).

7-5. 모터 기판 만들기#

MOSFET 4개, 다이오드 4개, 풀다운 저항 4개, 분압 저항 2개를 만능기판 한 조각에 모읍니다. 아래 배치도는 부품을 꽂는 윗면에서 본 모습입니다. 주황색 굵은 선은 뒷면에서 납으로 잇는 연결이고, 위에서 본 위치 그대로 그렸습니다.

1. 기판 자르기

  1. 3×7cm 기판에서 구멍 기준 가로 11칸 × 세로 8칸을 잘라 냅니다. 자를 선을 따라 커터칼로 양면을 여러 번 긋고 꺾은 뒤, 가장자리를 줄로 다듬습니다.
  2. 윗면 왼쪽 위 구석에 펜으로 점을 찍어 A1로 정합니다. 가로는 왼쪽부터 A~K, 세로는 위부터 1~8입니다.

2. 다이오드 4개 꽂기

  1. 다이오드 다리를 몸통 양 끝에서 꺾어, 다리 사이가 구멍 3칸(약 7.6mm)이 되게 합니다.
  2. 검은 띠가 있는 쪽이 1번 줄로 가게 해서 A1–A4, C1–C4, E1–E4, G1–G4에 꽂습니다. 띠 방향이 반대면 MOSFET이 켜질 때 배터리가 단락되니 꼭 다시 봅니다.
  3. 뒷면에서 납땜하고 다리를 잘라 냅니다. 잘라 낸 다리는 버리지 말고 모아 둡니다. 뒤에서 레일과 MOSFET 다리로 씁니다.

3. 분압 저항 2개 꽂기

  1. 저항 하나는 I1–I4(구멍 3칸)에, 하나는 J4–J8(구멍 4칸)에 눕혀 꽂습니다. 저항은 방향이 없습니다.
  2. 뒷면에서 납땜하고 다리를 잘라 냅니다.

4. 풀다운 저항 4개 세워 꽂기

  1. 저항 몸통을 세우고, 위쪽 다리를 U자로 꺾어 내려서 두 다리가 구멍 1칸 간격이 되게 합니다.
  2. A7–A8, C7–C8, E7–E8, G7–G8에 꽂고 뒷면에서 납땜합니다.

5. MOSFET 4개에 다리 달기

AO3400A는 다리 간격이 만능기판 구멍 간격과 맞지 않습니다. 그래서 다리마다 짧은 선을 납땜해 구멍에 꽂을 수 있는 부품으로 만듭니다.

  1. 모아 둔 다이오드 다리를 1cm 길이로 12개 자르고 곧게 폅니다.
  2. 캡톤 테이프를 접착면이 위로 오게 책상에 붙이고, 그 위에 MOSFET을 글자 면이 위로 오게 올려 고정합니다.
  3. 세 다리에 플럭스를 바르고 납을 아주 조금씩 먹입니다.
  4. 다리마다 1cm 선을 바깥쪽으로 뻗게 대고 인두로 1~2초만 눌러 붙입니다. 한 다리를 오래 데우면 다른 다리의 납이 녹으니 짧게 끊어서 합니다.
  5. 나머지 3개도 같은 방법으로 만듭니다.

7. 뒷면 연결하기 (배치도의 주황색 선)

  1. 레일 2줄: 모아 둔 다리 중 긴 것을 펴서 1번 줄 A1~K1 위에 얹고, 패드마다 납땜합니다. 8번 줄 A8~K8도 똑같이 합니다. 1번 줄이 배터리 +, 8번 줄이 GND입니다.
  2. 채널마다 4곳 (패드끼리 납으로 잇거나, 짧은 다리 조각을 얹어 납땜):
    • X4–Y4 (다이오드와 MOSFET D)
    • Y3–Y4 (모터 − 자리와 MOSFET D)
    • X6–X7 (MOSFET G와 풀다운 저항)
    • Y6–Y7–Y8 (MOSFET S를 GND 줄로)
  3. 나머지 3곳: I4–J4 (분압 가운데), K1–K2, K7–K8.

이어지면 안 되는 곳: 채널 사이(B–C, D–E, F–G, H–I)는 가로로 이어지면 안 됩니다. 그리고 각 채널의 Y1과 Y3 사이(Y2)는 비워 둡니다. Y1(+)과 Y3(−)이 이어지면 모터가 단락됩니다.

J4 ↔ 8번 줄, J4 ↔ 1번 줄저항둘 다 약 10kΩ

점검이 끝나면 뒷면에 튀어나온 다리를 바짝 자르고, 선을 붙일 자리(동그라미 숫자)만 남기고 캡톤 테이프로 덮습니다.

7-7. 전원선과 신호선 연결#

  1. 피그테일 극성 먼저 확인. PH2.0 피그테일을 배터리에 꽂고, 멀티미터 전압 모드로 빨간 선이 +(3.7~4.2V)인지 확인합니다. 판매처마다 극성이 반대인 경우가 있습니다. 확인 후 배터리는 다시 뺍니다.
  2. XIAO 뒷면의 BAT+, BAT− 패드에 26AWG 빨강·검정 선을 납땜합니다. 패드에 납을 먼저 얇게 올리고, 예비 납땜한 선을 대고 1~2초 눌러 붙입니다.
  3. 아래 표대로 선을 연결합니다. 기판 쪽은 동그라미 숫자 자리 패드에 선을 얹어 납땜합니다. 선 길이는 프레임 위의 실제 자리를 보고 정하고, 여유는 1cm만 둡니다.

M2가 D1이 아니라 D8로 가는 데 주의합니다. 펌웨어가 배터리 전압을 D1(GPIO2)에서만 읽도록 고정되어 있어서 D1을 배터리 전압에 내줬습니다.

7-8. 전원 넣고 배터리 전압 확인#

  1. USB를 뺀 상태에서 배터리를 꽂습니다. 10초 동안 뜨거워지는 부품이나 냄새가 없는지 손으로 확인합니다. 이상하면 바로 뺍니다.
  2. 배터리를 꽂은 채로 USB를 연결하고 아래 코드를 업로드합니다.
// 배터리 전압 확인: D1(GPIO2)에 연결한 분압 회로를 읽음
const int PIN_BAT = 2;  // D1

void setup() {
  Serial.begin(115200);
}

void loop() {
  uint32_t mv = analogReadMilliVolts(PIN_BAT) * 2;  // 저항 2개로 절반이 됐으니 2배
  Serial.printf("배터리 %.2f V\n", mv / 1000.0);
  delay(500);
}
  1. 시리얼 모니터 값과 멀티미터로 잰 배터리 전압(1번 줄 ↔ 8번 줄)을 비교합니다. 차이가 0.1V 안쪽이면 정상입니다.
  2. USB가 꽂혀 있으면 XIAO가 배터리를 충전하는 중이라 값이 조금 높게 나올 수 있습니다. 정확히 보려면 USB를 뺀 직후 멀티미터 값과 비교합니다.

7-9. 모터 연결과 방향 확인#

프로펠러를 전부 뺀 상태에서만 합니다.

  1. 배터리와 USB를 뺍니다.
  2. 모터 선을 기판까지 닿는 길이로 자르고(여유 5mm), 피복을 2mm 벗겨 예비 납땜합니다.
  3. 채널마다 모터의 두 선 중 하나를 Y1(+), 다른 하나를 Y3(−) 윗면 패드에 얹어 납땜합니다. 어느 선이 +인지 몰라도 괜찮습니다. 아래 테스트에서 방향을 보고 반대면 바꿉니다.
    • M1(앞오른쪽 모터) → B1, B3
    • M2(뒤오른쪽 모터) → D1, D3
    • M3(뒤왼쪽 모터) → F1, F3
    • M4(앞왼쪽 모터) → H1, H3
  4. 모터 축에 테이프 조각을 깃발처럼 붙이면 도는 방향이 잘 보입니다.
  5. 배터리를 꽂고 USB를 연결한 뒤 아래 코드를 업로드합니다.
// 모터 순서·방향 확인 (프로펠러를 꼭 빼고!)
const int MOTOR_PIN[4] = {1, 7, 3, 4};  // D0, D8, D2, D3
const char *MOTOR_NAME[4] = {"M1 앞오른쪽, 반시계", "M2 뒤오른쪽, 시계",
                             "M3 뒤왼쪽, 반시계", "M4 앞왼쪽, 시계"};
const int TEST_DUTY = 50;  // 255 중 50, 약 20%

void setup() {
  Serial.begin(115200);
  for (int i = 0; i < 4; i++) {
    ledcAttach(MOTOR_PIN[i], 15000, 8);  // 15kHz, 8비트 (펌웨어와 같음)
    ledcWrite(MOTOR_PIN[i], 0);
  }
  delay(3000);
}

void loop() {
  for (int i = 0; i < 4; i++) {
    Serial.printf("%s 돌리는 중\n", MOTOR_NAME[i]);
    ledcWrite(MOTOR_PIN[i], TEST_DUTY);
    delay(2000);
    ledcWrite(MOTOR_PIN[i], 0);
    delay(1500);
  }
  Serial.println("한 바퀴 끝, 5초 뒤 다시 시작");
  delay(5000);
}

드론을 위에서 내려다보면서, 시리얼 모니터에 나온 모터가 그 자리에서 그 방향(배치도)으로 도는지 봅니다.

증상고치는 법
다른 자리의 모터가 돎XIAO 쪽 게이트 선(D0, D8, D2, D3)이 바뀜. 7-7 표와 비교해 다시 납땜
자리는 맞는데 방향이 반대그 모터의 두 선(Y1, Y3)을 서로 바꿔 납땜
안 돎게이트 선, X6–X7 연결, MOSFET 다리 납땜 확인
코드를 올리기 전부터 계속 돎그 채널의 Y4와 GND가 이어짐. 바로 배터리를 빼고 7-6 점검
컴파일 오류 ledcAttach보드 매니저의 esp32를 3.x로 업데이트

4개가 모두 맞으면 배터리와 USB를 뺍니다.

7-10. 프레임에 고정#

  1. GY-521: 부품 면이 위로 오고, 기판에 인쇄된 Y 화살표가 뒤(꼬리) 쪽, X 화살표가 왼쪽을 가리키게 놓습니다. 펌웨어가 센서를 이 방향으로 붙였다고 보고 계산합니다. 프레임 가운데 판에 폼테이프로 붙이고, 5°보다 더 기울면 펌웨어 시작 점검에서 실패하니 최대한 평평하게 붙입니다.
  2. XIAO: GY-521 위에 폼테이프로 붙입니다. USB-C 포트가 바깥쪽을 향하게 해야 나중에 펌웨어를 올리기 편합니다. 뒷면 BAT 패드의 납땜이 테이프에 눌려 떨어지지 않았는지 봅니다.
  3. 안테나: XIAO 상자에 든 안테나를 XIAO의 안테나 커넥터(작고 동그란 단자)에 딸깍 소리가 나게 끼우고, 프로펠러에 닿지 않는 프레임 위쪽에 캡톤으로 붙입니다. 안테나 없이는 와이파이가 거의 닿지 않습니다.
  4. 모터 기판: 프로펠러가 도는 원 밖, 가운데에 가까운 곳에 폼테이프로 붙입니다.
  5. 선 정리: 남는 선은 캡톤으로 프레임에 붙여서, 프로펠러가 도는 원 안으로 들어가는 선이 하나도 없게 합니다.
  6. 배터리: 프레임의 배터리 자리에 끼우고, 무게 중심이 가운데에 오게 앞뒤 위치를 맞춥니다.

8-5. 휴대폰 앱 연결#

  1. 앱 설치: 아이폰은 앱 스토어에서 ESP-Drone을 설치합니다. 안드로이드는 ESP-Drone 시작 안내의 QR 코드로 설치 파일을 받습니다.
  2. USB를 빼고, 드론을 평평한 곳에 놓은 채 배터리를 꽂습니다. 5초 동안 건드리지 않습니다 (센서 영점을 잡는 시간).
  3. 휴대폰 와이파이 목록에서 ESP-DRONE_으로 시작하는 이름에 연결합니다. 비밀번호는 12345678입니다. "인터넷 없음" 안내가 나와도 연결을 유지합니다.
  4. 앱을 열고 Connect를 누릅니다. 연결되면 XIAO의 주황 LED가 빠르게 깜빡입니다.
  5. 앱 설정은 처음엔 기본값을 씁니다. 기본은 Mode 2라서 왼쪽 스틱이 추력(위·아래)과 회전, 오른쪽 스틱이 앞뒤·좌우입니다.

9. 첫 비행#

9-1. 프로펠러 없이 마지막 점검#

센서 방향이 틀리면 이륙하자마자 뒤집힙니다. 프로펠러를 달기 전에 펌웨어가 기울기에 맞게 반응하는지 확인합니다.

  1. 프로펠러가 없는 상태에서 배터리를 꽂고 앱을 연결합니다.
  2. 추력을 아주 조금 올려 모터 4개가 천천히 돌게 합니다.
  3. 드론을 손으로 잡고 오른쪽을 아래로 기울입니다. 오른쪽 모터(M1, M2) 소리가 높아지면 정상입니다. 내려간 쪽을 다시 들어 올리려고 그쪽을 세게 돌리는 것입니다.
  4. 앞을 아래로 기울입니다. 앞 모터(M1, M4) 소리가 높아지면 정상입니다.
  5. 반대쪽 모터가 세지면 GY-521 방향이 틀린 것입니다. 7-10의 화살표 방향을 다시 봅니다.
  6. 추력을 0으로 내리고 배터리를 뺍니다.

9-2. 프로펠러 달기#

  1. 프로펠러도 방향이 있습니다. M1·M3에는 반시계 방향용, M2·M4에는 시계 방향용을 끼웁니다 (배치도).
  2. 헷갈리면 날개를 봅니다. 도는 방향으로 먼저 나가는 날개 가장자리가 위로 들린 쪽이어야 바람을 아래로 보냅니다.
  3. 축 끝까지 꾹 눌러 끼웁니다.
  4. 확인: 드론을 손으로 꽉 잡고 추력을 살짝 올렸을 때, 덕트 4개 모두 아래로 바람이 나오면 맞습니다. 위로 나오는 곳이 있으면 그 프로펠러가 반대입니다.

9-3. 첫 이륙#

장소: 넓은 실내, 평평한 바닥, 주변 2m 안에 사람과 물건이 없는 곳.

  1. 완충한 배터리(약 4.2V)를 준비합니다.
  2. 드론을 바닥에 놓습니다. 드론의 앞쪽이 내가 보는 방향과 같게, 즉 내가 드론 뒤에 서게 놓습니다. 그래야 스틱 방향과 드론 움직임이 같습니다.
  3. 배터리를 꽂고 5초 동안 건드리지 않습니다.
  4. 앱을 연결합니다.
  5. 추력을 아주 천천히 올립니다. 드론이 가벼워지면서 한쪽으로 미끄러지면 그 방향을 기억합니다.
  6. 바닥에서 10~20cm 뜨면 그 높이에서 몇 초 버틴 뒤 추력을 천천히 내려 착륙합니다.
  7. 뜨자마자 한쪽으로 계속 흐르면, 앱 설정의 Roll trim(좌우)과 Pitch trim(앞뒤)으로 반대쪽을 조금씩 보정합니다.
  8. 위험하다 싶으면 추력을 바로 0으로 내립니다. 낮게 날고 있어서 떨어져도 크게 다치지 않습니다.

처음에는 30초씩 여러 번 띄웁니다. 배터리 하나로 2~3분까지만 날립니다. 펌웨어는 전압이 3.2V 아래로 떨어지면 경고만 하고 스스로 착륙하지 않습니다.

9-4. 비행 뒤 점검#

  1. 착륙하면 바로 배터리를 뺍니다.
  2. 모터, MOSFET, 다이오드를 손가락으로 만져 봅니다. 다이오드만 유난히 뜨거우면 1A급 쇼트키 다이오드(SS14, B5819W)로 바꿉니다. 자리와 방향(띠가 1번 줄)은 같습니다.
  3. 멀티미터로 배터리 전압을 잽니다. 3.7V 위에서 끝내는 것이 배터리에 좋습니다. 3.5V 아래면 다음부터 비행 시간을 줄입니다.
  4. CX405 충전기나 XIAO(USB-C)로 충전합니다.
  5. 보관할 때는 배터리를 드론에서 빼 둡니다. 며칠 이상 안 쓰면 3.8V 근처로 맞춰 둡니다.

9-5. 문제 해결#

증상원인고치는 법
뜨자마자 뒤집힘모터 순서·방향, 프로펠러 방향, 센서 방향 중 하나7-9, 9-2, 9-1 순서로 다시 확인
한쪽으로 계속 흐름센서가 살짝 기울게 붙음, 무게 중심이 쏠림트림으로 보정. 많이 흐르면 배터리 위치를 반대쪽으로
추력을 끝까지 올려도 안 뜸무거움7-11에서 무게 다시 재고 줄이기
날다가 갑자기 꺼짐, 연결이 끊김전압이 순간적으로 떨어져 XIAO가 재시작배터리 충전 상태, 전원선 굵기(26AWG)와 납땜 확인
모터 하나만 약함그 채널 납땜 불량, 모터 불량7-9 테스트 코드로 그 모터만 돌려 비교
앱이 연결이 안 됨와이파이를 다른 데 연결함, 안테나 빠짐휴대폰 와이파이가 ESP-DRONE에 붙어 있는지, 안테나 커넥터 확인

비행 규정#

  • 최대이륙중량 250g 이하라서 조종 자격은 필요 없습니다.
  • 무게와 상관없이 비행금지구역과 제한구역(공항 주변 등)에서는 승인이 필요합니다. 서울은 제한 구역이 많아서, 밖에서 날리기 전에 드론원스톱이나 Ready to fly 앱으로 확인합니다.
  • 처음에는 실내에서 날리는 것이 가장 간단합니다.
