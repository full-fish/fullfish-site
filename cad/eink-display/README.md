# e-ink 디스플레이 케이스 3D 프린팅 파일

`/projects/eink-display/` 계획 문서의 기기 A(케이스 디자인 ② 현관문 자석형)와 기기 B(쐐기형 책상 케이스)를 출력하는 STL과, 그 STL을 만드는 스크립트입니다. 부품 치수는 제조사 도면과 보드 파일에서 가져왔고, 출처는 맨 아래에 있습니다.

모든 STL은 출력 방향대로 바닥에 놓여 있어서 슬라이서에 그대로 올리면 됩니다. 서포트는 필요 없습니다.

## 먼저 테스트 조각부터

| 파일 | 크기 (mm) | 확인할 것 |
| --- | --- | --- |
| `stl/device-a/a0_test_bottom_left.stl` | 83 × 14 × 14.5 | EN04 버튼, 스위치, USB-C 위치. 보드 기둥 나사 구멍. 패널 모서리 |
| `stl/device-b/b0_test_front_bottom.stl` | 125 × 45 × 5 | 그릴 구멍, 스피커 나사 기둥, 센서 칸, 화면 아래 테두리 |

맞지 않으면 스크립트 위쪽의 값을 고친 뒤 다시 실행합니다 ([다시 만들기](#다시-만들기)).

## 기기 A: 7.3인치 현관문 자석형 (186 × 128 × 18)

| 파일 | 크기 (mm) | 출력 방향 |
| --- | --- | --- |
| `a1_front_frame.stl` 앞틀 | 186 × 128 × 14.5 | 앞면이 바닥 |
| `a2_back_plate.stl` 뒷판 | 186 × 128 × 11.3 | 바깥면(문에 닿는 면)이 바닥 |
| `a3_leg.stl` 다리 | 59 × 89.6 × 5.1 | 바깥면이 바닥 |
| `a4_button_cap_x3.stl` 버튼 캡 3개 | 지름 7 | 넓은 쪽이 바닥 |
| `a5_bay_cover.stl` 다리 칸 가림판 | 63.6 × 86.2 × 1 | 눕혀서 |

뒷판 높이가 11.3mm인 것은 판(3.5mm)에 경첩 마디와 배터리 울타리가 안쪽으로 붙어 있어서입니다. 베드는 가로 200mm 이상이 필요합니다.

**조립에 필요한 것:** M2×6 나사 6개(뒷판 4, 보드 2), M2 열 인서트 4개, 지름 10 두께 3 자석 6개, 1.75mm 필라멘트 토막 약 20mm 2개, 3mm 폼테이프, 펠트, 다리 끝 고무 패드

**조립 순서**
1. 앞틀 나사 기둥 4개에 열 인서트를 넣습니다.
2. 버튼 캡 3개를 아래 벽 구멍에 안쪽에서 끼웁니다.
3. 패널을 넣고 테두리에 얇은 양면테이프를 붙여 고정합니다. FPC는 아래 홈으로 뒤로 접습니다.
4. EN04를 3mm 폼테이프 위에 올리고, 왼쪽 두 구멍을 M2 나사로 기둥에 고정합니다.
5. 자석 6개를 같은 극이 바깥을 보게 뒷판 홈에 에폭시로 붙입니다.
6. 다리를 칸에 넣고, 양쪽 핀 홈에 핀을 하나씩 놓아 경첩 쪽으로 밀어 넣은 뒤, 홈을 글루로 막습니다.
7. 가림판을 다리 칸 안쪽 면에 붙입니다. 경첩 쪽 3mm는 비워 둡니다.
8. 배터리를 울타리 안에 넣고 커넥터를 꽂은 뒤, 뒷판을 M2 나사 4개로 닫습니다.

**경첩:**
- 다리는 0~29°에서 걸림 없이 움직이고, 30°에서 다리 끝 멈춤면이 다리 칸 위쪽 벽에 평평하게 닿습니다. 스크립트가 각도별로 겹침을 계산해서 확인합니다.
- 경첩 축은 바닥 끝에서 94mm 높이에 있습니다. 이 높이에서는 다리를 폈을 때 화면이 약 22~23° 뒤로 기웁니다(다리 끝 패드 두께에 따라).

## 기기 B: 4.26인치 쐐기형 (125 × 103.4 × 50, 앞면 경사 길이 107)

| 파일 | 크기 (mm) | 출력 방향 |
| --- | --- | --- |
| `b1_front_plate.stl` 앞판 | 125 × 107.5 × 16 | 앞면이 바닥 |
| `b2_body.stl` 몸통 | 125 × 103.4 × 45.9 | 뒤 끝이 바닥 (바닥 닿는 면이 좁아 브림 권장) |
| `b3_back_cover.stl` 뒷덮개 | 125 × 103.4 × 18.4 | 바깥면이 바닥 |
| `b4_sensor_back.stl` 센서 칸 뒷판 | 23.4 × 27.7 × 1 | 눕혀서 (잘라 낸 모서리가 몸통 왼쪽 아래 구석으로 감) |

뒷덮개가 18.4mm인 것은 판(2mm)에 XIAO 받침벽이 서 있어서입니다. 앞면은 15° 뒤로 기울어 있습니다.

**조립에 필요한 것:** M2×6 나사 9개(앞판 3, 뒷덮개 4, 스피커 2), M2 열 인서트 7개, 스펀지 테이프, 글루건

**조립 순서**
1. 앞판 나사 기둥 3개와 몸통 뒤 끝 기둥 4개에 열 인서트를 넣습니다.
2. 패널을 앞판 테두리 안에 넣습니다. FPC는 왼쪽으로 나와 뒤로 꺾습니다.
3. 스피커 앞면에 스펀지 테이프를 붙이고, 아래 두 구멍을 M2 나사로 기둥에 고정합니다.
4. SHT40을 센서 칸 앞벽 안쪽에 붙이고, 전선은 천장 홈으로 빼서 글루로 메웁니다.
5. 칸 벽 두 개의 뒤 끝에 센서 칸 뒷판을 글루로 붙입니다.
6. 천장 왼쪽 끝과 옆벽 아래 끝에 마스킹테이프를 한두 겹 붙여 몸통과의 0.25mm 틈을 막습니다.
7. 앞판을 몸통 앞에 끼웁니다. 몸통 뒤쪽 열린 곳으로 드라이버를 넣어 귀 3개의 나사를 조이고, 뒷판의 왼쪽과 아래 테두리를 글루로 메웁니다.
8. 내부 부품을 넣고 뒷덮개를 M2 나사 4개로 닫습니다.

## 처음 계획에서 바뀐 점

실제 부품 치수를 넣어 보니 처음 계획대로는 겹치는 곳이 있어서 아래처럼 바꿨습니다. 계획 페이지의 글은 이 내용에 맞춰 두었습니다.

**기기 A**
- **아래쪽 나사:** 두 개를 모서리 대신 옆벽 중간(아래 끝에서 56mm)으로 옮겼습니다. EN04가 80 × 41.2mm라 왼쪽 아래 모서리 기둥과 겹치기 때문입니다.
- **USB-C:** 구멍 대신 뒷판 쪽으로 열린 홈입니다. 플러그 몸통(7mm)의 윗단이 앞틀 끝에 0.5mm까지 닿아서, 뒷판이 구멍의 윗변이 되게 했습니다.
- **배터리 자리:** 다리 칸 오른쪽에 가로로 둡니다(앞에서 볼 때). 보드 바로 오른쪽은 다리 칸과 가림판 자리이기 때문입니다. 배터리 울타리는 뒷판에 붙어 있습니다.
- **경첩 핀:** 한 개를 관통시키는 대신 약 20mm 핀 두 개를 뒷판 안쪽 홈에서 밀어 넣습니다. 뒷판 가장자리에 긴 구멍을 내지 않기 위해서입니다.
- **다리와 가림판 크기:** 다리는 59 × 89.6mm, 가림판은 63.6 × 86.2mm입니다(계획은 59 × 90, 64 × 88). 경첩 높이와 30° 멈춤면에 맞춘 결과입니다.

**기기 B**
- **센서 칸:**
  - 안쪽이 21 × 34 × 14에서 21 × 28 × 14가 됐습니다. 화면 아래 모서리와 겹치지 않게 줄였고, SHT40(25.4mm)은 들어갑니다.
  - 칸 벽 두 개는 몸통이 아니라 앞판에 붙였습니다. 몸통은 뒤 끝을 바닥에 두고 뽑아서, 몸통에 붙이면 벽 아래가 허공에 뜨기 때문입니다.
- **스피커:** 아래 구멍 2개만 나사로 고정합니다. 스피커 뒤쪽 아래 모서리가 바닥 벽에 닿지 않으려면 스피커를 너무 내릴 수 없어서, 위 두 구멍이 화면 뒤에 가려집니다. 위쪽은 스펀지 테이프로 붙입니다.
- **앞판 나사:** 3개(위 2, 오른쪽 아래 1)입니다. 왼쪽은 화면 FPC와 센서 칸 때문에 자리가 없습니다.
- **XIAO 받침벽:** 몸통 대신 뒷덮개에 세웠습니다.
- **화면과 어댑터 방향:** 화면을 가로로 두면 FPC가 왼쪽 짧은 변으로 나옵니다. 어댑터는 화면 뒤 왼쪽에 둡니다.
- **USB-C 위치는 가정값입니다:**
  - 처음 계획은 만능기판을 세로(6.1cm가 위아래)로 뒀는데, 그러면 XIAO의 USB-C가 위나 아래를 향합니다. 오른쪽 옆면으로 빼려고 만능기판을 가로로 어댑터 오른쪽에 둡니다. 어댑터 58.6mm와 만능기판 61mm를 합치면 몸통 안쪽 폭 120.6mm에 여유가 1mm뿐입니다.
  - 지금 구멍은 이 배치 기준입니다: 앞면 아래 끝에서 경사를 따라 70mm, 앞면에서 안쪽으로 20mm.
  - 배치가 정해지면 `USB_V`, `USB_W` 값을 고칩니다.

## 받은 뒤 실측해서 고칠 값

| 파일 | 값 | 뜻 |
| --- | --- | --- |
| `device_a.py` | `BOARD_Z` | EN04 PCB 앞면 높이 (폼테이프 두께에 따라) |
| `device_a.py` | `EDGE_PARTS`, `USB_DZ` | 버튼, 스위치, USB-C 높이 (보드 파일에 없는 부품 높이는 추정값) |
| `device_a.py` | `FPC_X` | 패널 FPC 위치 (도면 좌우 해석에 따라 1mm 차이, 홈은 넉넉히 냄) |

| `device_b.py` | `PANEL_*`, `SPK_*` | 터치 패널, 스피커 실측 |

## 다시 만들기

Python 3.10 이상에서:

```sh
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt     # macOS, Linux는 .venv/bin/pip
.venv/Scripts/python device_a.py
.venv/Scripts/python device_b.py
```

실행하면 STL을 다시 저장하고, 마지막에 간섭 검사 결과를 출력합니다. 간섭 검사는 조각끼리, 그리고 조각과 패널, 보드, 배터리, 스피커 모형이 겹치는 부피를 계산하며 0이어야 정상입니다.

STL을 고친 뒤에는 사이트 계획 페이지의 미리보기 그림도 다시 만듭니다.

```sh
.venv/Scripts/python render_previews.py
```

`stl/` 아래 STL마다 `public/projects/eink-display/img/stl-<이름>.webp`(1600×1000)와 `-800.webp`를 덮어씁니다. 그림 위 글자는 Windows의 맑은 고딕으로 쓰고, 그 글꼴이 없으면 글자 없이 그립니다.

스크립트 좌표는 "앞에서 볼 때 X 오른쪽, Y 위, Z 뒤쪽"입니다. 이 좌표는 실제 공간의 거울상이라 STL로 저장할 때 X를 뒤집습니다.

## 치수 출처

- EN04 보드: Seeed KiCad 파일 V1.2 (`202004502_XIAO_ePaper_Display_Board_EN04_V1_SCH_and_PCB.zip`)
- 7.3인치 패널: GDEP073E01 도면 (laskakit 배포 PDF 5쪽)
- 4.26인치 터치 패널: Good Display GDEQ0426T82-T01C 도면
- 스피커: Adafruit 3351 데이터시트 4쪽
- XIAO ESP32-S3 Plus: Seeed KiCad 파일 V1.1
- FPC 연장 보드: Adafruit 2571 제품 페이지
